# Learner journeys

These describe the future teaching page. The initial HTML currently guides contributors to documentation. [UX](../../UX.md) owns interaction behavior; [learning objectives](learning-objectives.md) owns educational outcomes.

## Journey 1 — I found a component and want to know what it does

Open Explore -> search/category or focus board part -> activate component -> read purpose, made-of and mechanism -> expand technical depth/source -> close/return. Success: learner names role and explains a conditional consequence of absence. Empty search offers clear filters; no hover-only information.

## Journey 2 — I want to go from Arduino board to electron

Select ZU4 -> zoom package -> die -> CPU -> circuit/gate -> MOSFET -> semiconductor -> silicon crystal -> atom -> electron/cloud. At each step read model label, composition/mechanism and source. Choose Back to revisit actual history and return to ZU4. Success: learner distinguishes organizational blocks from physical nesting and does not assume every component is a transistor.

## Journey 3 — I want to understand why the LED lights

Select built-in L -> Signal Journey LED ON -> pause at D13/U5B control -> inspect +5V-powered output/RN2A/L/return -> zoom junction/carriers -> photon. Success: learner explains buffer versus control path and recombination/light without consumed electrons.

## Journey 4 — I want to rebuild the board

Open Assemble -> select part -> choose/drag matching slot -> receive correct/wrong feedback -> use hint/reset as needed -> complete progress. Keyboard/tap placement is always available. Success: part roles and positions recognized; this remains a matching exercise rather than literal manufacturing instruction.

## Journey 5 — I want to study for a quiz

Review terminology/objectives -> select Quiz -> choose/submit -> read explanation/source -> next -> final score -> revisit related node -> retry. Success: learner can correct a misconception, not merely recall colors. Scoring is once per question; no account/storage needed.

## Journey 6 — I use only a keyboard

Skip to main -> component list -> Enter -> detail -> depth/zoom buttons -> Back -> mode controls -> Assemble select/place -> Quiz radios/submit. Close temporary sheet with Escape and return focus. Success: every essential outcome available without precise dragging or motion.

## Teacher demonstration

Directly select a scene/journey -> pause -> expand technical explanation -> ask learner for prediction -> step cause/effect -> open citations. Text remains legible when projection or reduced motion prevents animation. Teacher can recover to board without restarting.
