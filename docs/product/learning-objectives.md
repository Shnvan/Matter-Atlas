# Learning objectives

Measurable outcomes align with original section numbers. Each outcome is checked by a prediction, explanation, identification or completed navigation; time spent and animation views alone do not prove learning. [Requirements](../../REQUIREMENTS.md) owns acceptance/status.

| Section | After this section the learner can… |
| --- | --- |
| 0 / Help | Identify six modes and explain why illustrations need scale/model labels. |
| 1 / History | Describe beginner-oriented origins and distinguish attributed historical claims from verified chronology. |
| 2 / Anatomy | Locate main/USB MCUs, clocks, protection, regulators, reset and headers and state their roles. |
| 3 / PCB | Distinguish trace, pad, via, plated hole and substrate; compare surface and through-hole assembly. |
| 4 / Families | Choose physically appropriate resistor/capacitor/diode/LED/clock/fuse/ferrite/connector/switch/solder branches. |
| 5 / Package | Distinguish visible package from die and describe general electrical connections with variation limits. |
| 6 / Die | Identify functional blocks and explain why a conceptual map is not an exact floorplan; include analog circuitry. |
| 7 / Logic | Predict NOT/AND/OR/NAND outputs and connect voltage/transistor state to stored/processed information. |
| 8 / Memory | Distinguish SRAM volatility from flash/EEPROM retention and avoid claiming exact undocumented cell structures. |
| 9 / MOSFET | Name device regions and explain gate field -> carriers -> channel/current, with no mechanical motion. |
| 10 / Semiconductor | Explain pure silicon, doping, n/p type neutrality, donor/acceptor examples and holes as effective carriers. |
| 11 / Materials | Classify element/compound/mixture and material role; distinguish verified board presence from general examples. |
| 12 / Crystal | Compare covalent silicon, metallic conduction and dielectric behavior through bonding and electron states. |
| 13 / Atom | Explain nucleus/electron cloud, atomic number and neutrality while rejecting literal planetary trajectories. |
| 14 / Electrical | Define charge/voltage/current/field/resistance/capacitance and distinguish drift, propagation and energy transfer. |
| 15 / Photon | Explain LED recombination/light and distinguish photon energy/frequency from brightness. |
| 16 / Nucleus | Distinguish protons/neutrons from electrons and identify the particle bonus as beyond normal electronics. |
| 17 / Signal | Trace USB/external supply, upload, buffered L LED and ADC paths with control/parallel/return branches. |
| 18 / Pins | Identify GPIO/ADC/PWM/interrupt/serial/power functions and duplicated SDA/SCL nets. |
| 19 / Recap | Traverse MCU, LED, resistor, capacitor and conductor branches and justify their differences. |
| 20 / Limits | Identify simplified graphics, unknown geometry/scales, model conventions and quantum limits. |

Quiz questions sample anatomy, materials, component purpose, MCU, transistor, semiconductor and atomic/electrical concepts. A teacher can ask the learner to explain one correct and one incorrect pathway aloud. Avoid testing unsupported manufacturing trivia. Foundation delivery documents these outcomes; learner outcomes have not yet been tested.
