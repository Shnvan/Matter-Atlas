# Initial interface audit

Date: 2026-10-08. Scope: foundation guide before application migration. The existing guide is useful contributor documentation, not a learner workspace. Foundation validator passed: 42 files, 103 requirements, 32 sources, 8 decisions, 30 tasks, 116 CAD elements.

## Captured observations

Desktop 1440px and mobile 360px screenshots were captured in the temporary gotophysics-redesign-audit directory. The mobile document extends approximately 4092px. The first screen is dominated by an oversized introduction and repeated documentation cards. No board SVG, component selection, inspector or teaching-mode controls exist. Dark blue surfaces and cyan links suggest a documentation dashboard. Existing links and keyboard behavior are useful to preserve under contributor navigation.

## Target and acceptance

Make the Arduino visible immediately; keep navigation concise and documentation secondary. A restrained warm workspace contains a CAD-derived board, system/component navigator and progressive inspector. Evaluate at 360, 768, 1024 and 1440px in both themes. Compare selected, focused, isolated, hidden, exploded and microscopic views. Check typography/spacing and object prominence rather than reproducing card-based content.

[DESIGN](../../DESIGN.md) owns the design system; [UX](../../UX.md) owns interactions. This audit is historical evidence, not a claim that the replacement has passed visual QA.
