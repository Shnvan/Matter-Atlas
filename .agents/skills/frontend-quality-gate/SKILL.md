# Frontend Quality Gate

Read [TESTING](../../../TESTING.md), [ACCESSIBILITY](../../../ACCESSIBILITY.md), [ARCHITECTURE](../../../ARCHITECTURE.md) and the affected [TASKS](../../../TASKS.md). Run relevant strict type/lint/unit/build checks and browser acceptance. Exercise keyboard parity, focus restoration, reduced motion, mobile sheets, invalid IDs and offline export. Inspect screenshots where layout changed. Record commands, browser, results and unavailable checks; only mark DONE with nonempty Acceptance evidence and satisfied dependencies. Run the dependency-free foundation validator after documentation changes.
