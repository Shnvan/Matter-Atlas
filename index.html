Reference and limits

The main reference is the published socketed Uno Rev3, UNO-TH_Rev3e schematic and CAD. The inventory reconciles 116 CAD elements, including board features and unpopulated footprints. An official-document discrepancy is recorded separately from a verified production variant.

The future visual scenes will be labeled educational, conceptual or simplified. Unsupported die geometry, process nodes, exact material recipes and numerical scales remain omitted or explicitly bounded in the research notebook.

For contributors: read the agent manual, handoff and task register first. Run powershell -NoProfile -ExecutionPolicy Bypass -File scripts/validate-foundation.ps1 to check the foundation.
