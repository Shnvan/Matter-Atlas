# Authoritative reference inventory

## Baseline and interpretation

Design baseline: Arduino A000066 socketed Uno Rev3, **UNO-TH_Rev3e** schematic and EAGLE CAD retrieved 2026-10-08. Sources [SRC-001](SOURCES.md) and [SRC-002](SOURCES.md) establish the reference design, not the exact contents of every sold unit. No clone or Uno R4 substitutions are included.

Inventory rows distinguish one physical footprint from its schematic units. U5A/B belong to one U5 package; RN1-RN4 each contain four resistor units. Quantity 1 below means one CAD element, not necessarily a fitted part. JP2 is not mounted; fiducials/test pads/jumpers are board features; FRAME1 is metadata. The `.brd` has 116 elements and every one is reconciled below. Component roles derived from circuit/net topology are documented interpretations of verified connectivity. Materials, suppliers, tolerances and interiors are unknown unless specifically cited.

Positions are original CAD package origins in mm, with x rightward and y upward; they are not necessarily component centers. Rotation/mirroring must be retained. Future SVG transform: xSVG = xCAD * 10, ySVG = (53.34 - yCAD) * 10, before scene margins; see [rendering](docs/engineering/rendering.md). These coordinates are sourced, not hand-estimated screen locations. Use package extents to hit-test connector overhangs.

## PCB features and provenance

CAD has routed copper on layers 1/16, four +5V/GND polygons across those layers, 82 via records, pads/SMD lands, stop/legend layers, and four plain 3.2 mm mounting holes. Counts describe the file, not laboratory measurement or production yield. Polygon presence does not prove a perfect continuous plane after fabrication. Through-hole and surface-mount footprints coexist. FD1-FD3 verify fiducials. Test-pad element names/positions appear individually above; not all require learner cards.

FR-4 is a general glass/epoxy PCB teaching model supported by [SRC-029](SOURCES.md). Exact Uno substrate procurement, dielectric chemistry, copper thickness, surface finish, plating, polymer housings, bond-wire metals, and solder alloy are not established by the CAD. Teach generic construction with that limitation. No solder composition is claimed.

## Circuit connections relevant to teaching

- X2 VBUS -> F1 -> USBVCC -> T1 -> +5V. U3 UVCC is connected to USBVCC separately.
- U5A compares CMP (equal RN1A/B VIN divider) to +3V3; its output commands T1. U5B follows SCK/D13 and drives L through RN2A.
- X1 PWRIN -> D1 -> VIN -> U1 -> +5V; POWER VIN is downstream of D1.
- +5V -> U2 -> +3V3. +5V -> L2 -> AVCC, with C10 shunting AVCC to GND.
- Z1/Z2 shunt D+/D- to USHIELD; RN3A/D are series data resistors. L1 connects USHIELD and UGND. GROUND links UGND and GND.
- U3 DTR -> C5 -> RESET; main pull-up RN1D, D2 clamp, button RESET. USB MCU has separate RESET2, RN1C and D3.

Source: SRC-001 / SRC-002. CAD library pad numbering may differ from manufacturer pin numbering; do not copy package pad numbers into a datasheet pin lesson without checking mapping.

## Differences and unsupported identities

[Current manual SRC-004](SOURCES.md) lists SPX1117M3-L-5 (U1), LMV358LIST-A.9 (U5), CGRA4007-G (D1), ECS-160-20-4X-DU (Y1), and a capacitor description for F1. Record as official-document discrepancies; a confirmed production variant needs its own dated schematic/BOM/board evidence. Baseline Y1 is a 16 MHz crystal with C9/C11; baseline Y2 is ceramic. Never replace either with a guessed oscillator module.
